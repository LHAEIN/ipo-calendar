# IPO Calendar

2026년 9월 국내 공모주 청약·상장 일정을 보여주는 반응형 웹 캘린더입니다.

## 주요 기능

- 월간 달력에서 청약일(빨간색)과 상장일(초록색) 구분
- 달력 아래 전체 기업 목록 제공
- 기업명 클릭 시 오른쪽 상세 패널 표시
- 희망·확정 공모가, 주관사, 환불일, 기관 수요예측 결과 제공
- 모바일 화면 지원

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. VS Code에서는 Live Server 확장 프로그램으로 실행할 수 있습니다.

## 데이터 기준
